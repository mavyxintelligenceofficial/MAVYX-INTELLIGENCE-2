# Technical Analysis Agent
# Per Volume IV §2.4: Technical Analysis Agents category

## Purpose
Analyzes price charts, technical indicators, and patterns to identify
trends, momentum, and key technical levels for Forex pairs.

## Domain
- Trend analysis (uptrend, downtrend, ranging)
- Support and resistance levels
- Moving averages (SMA, EMA)
- Momentum indicators (RSI, MACD)
- Volatility (ATR, Bollinger Bands)
- Chart patterns
- Breakout detection

## Inputs
- Symbol (e.g., EUR/USD)
- Current price data
- Historical candles (last 20+)
- Timeframe (1h, 4h, 1d)

## Outputs
- Signal: bullish / bearish / neutral
- Confidence: 0-100%
- Key findings with specific price levels
- Evidence from indicators
- Risk assessment
- Suggested actions

## Knowledge Domains
- Technical analysis concepts
- Forex basics (sessions, major pairs)
